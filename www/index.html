SMT2020 시뮬레이터

SMT2020 반도체 FAB 테스트베드 4종을 브라우저에서 실행합니다. Rust 이산 사건 엔진이 wasm으로 동작하며, 복제 1회를 Web Worker 1개가 맡아 CPU 코어 수만큼 병렬로 실행합니다. 모델·전략·검증은 README를 따릅니다.
